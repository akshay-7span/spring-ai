Meeting Title: Project Scope of Work – “TaskFlow Automation Platform”
Date: 2025-04-15
Participants: Sarah (Project Manager), Ethan (Client Representative), Leo (Tech Lead), Nora (UI/UX Designer)

Agenda:
- Define scope and deliverables for Phase 1
- Discuss tech stack and project timelines
- Identify client expectations

Discussion:
Ethan described that TaskFlow should help users create, assign, and track tasks with role-based access. Phase 1 will focus on user management, task assignment, and activity tracking.
Leo proposed using Spring Boot for backend APIs and React for the frontend. He also suggested integrating PostgreSQL as the database.
Nora shared initial wireframes for the dashboard and received positive feedback. A few layout adjustments were suggested to improve visibility on tablets.
Sarah emphasized that the MVP must be ready within eight weeks, with a demo to be presented at the end of June.
Ethan mentioned that reports and analytics can be deferred to Phase 2.

Decisions:
- Confirmed tech stack: Spring Boot + React + PostgreSQL.
- MVP delivery timeline: June 30th.
- Phase 1 modules: user management, task assignment, activity tracking.
- Reports and analytics deferred to next phase.
